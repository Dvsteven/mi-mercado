# Mi Mercado
PWA para gestionar el mercado: lista de compras, registro de precios por tienda (D1, Ara, Olímpica…), presupuesto quincenal, listas guardadas, lista sugerida por presupuesto y un "cerebro" con consejos. Los datos viven solo en el dispositivo (localStorage) con copia de seguridad JSON.
Sitio estático: se despliega en Vercel sin configuración.
